# グローバル エージェントガイドライン

## 目的

この文書は、Codex がどのリポジトリでも共通して参照する補助的な作業規約です。
プロジェクト固有の設計、外部サービス、運用契約、CLI 名、スキーマ定義はここには
記載しません。

## 優先順位

作業時は、次の順に規約を優先してください。

1. ユーザーから明示された指示
2. 対象リポジトリ内の `AGENTS.md`、`README.md`、`docs/`、設計文書
3. `pyproject.toml`、CI 設定、pre-commit 設定などの実際のツール設定
4. このグローバルガイドライン

この文書とプロジェクト内の規約が衝突する場合は、プロジェクト内の規約を優先します。
衝突や不足が作業結果に影響する場合は、採用した前提を明記してください。

## Python 実装

Python コードを変更する場合は、まず次の文書を参照してください。

```text
~/.codex/docs/python/DEVELOPMENT.md
```

同文書は、型定義、docstring、コメント、依存関係、設定、ログ、テスト、開発ツールの
汎用方針を定めます。具体的な Python バージョン、パッケージ名、コマンド名、外部
サービス、データスキーマは、対象プロジェクトの設定と文書に従ってください。

## 作業姿勢

- 既存の構成、責務分割、命名、テスト方針を読んでから変更する。
- 変更は要求された範囲に絞り、無関係なリファクタリングを混ぜない。
- 標準ライブラリと既存の依存関係を優先し、新規依存は必要性を説明できる場合だけ追加する。
- 外部サービス、ファイルシステム、データベースなどへの副作用は境界に閉じ込める。
- 挙動を変更した場合は、対象を絞った回帰テストを追加または更新する。
- 実行できなかった検証がある場合は、理由と残るリスクを明記する。
